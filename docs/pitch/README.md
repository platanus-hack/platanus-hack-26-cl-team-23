# Pitch de TRAZADA (Platanus Hack 26)

Material de la presentación de 3 minutos.

- **`deck.html`**: el deck para presentar. Se abre en Chrome sin internet (trae fuentes e imágenes adentro).
  Teclas: flechas para avanzar · F pantalla completa · N notas del guion · T cronómetro · V video de respaldo · A apéndice técnico · D modo claro/oscuro (parte en oscuro).
- `guion.md`: guion cronometrado (quién dice qué y cuándo).
- `demo-y-preguntas.md`: plan de demo con respaldos y preguntas probables del jurado.
- `deck-src.html` + `build.py`: fuente editable del deck. Después de editar, `python3 build.py` regenera `deck.html`.
- `andres.jpg`, `apendice/sistema.jpg`, `qr.svg`, `fonts/`: recursos que usa el deck.

Falta `demo-respaldo.mp4` (grabación de la demo para el plan B): se agrega aquí cuando esté.
